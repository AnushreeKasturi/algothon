What this console does

Thousands of ordinary events can hide one attacker. Intruder ingests security logs, scores every source, and — the part that matters — connects related events into a single incident with a step-by-step attack narrative instead of spraying isolated alerts.

Bring your own logs

Paste logs in this format (one event per line). Unknown lines are skipped gracefully.

ISO_TIME | SOURCE_IP | USER | ACTION | RESULT | DETAIL
2026-03-14T02:11:04Z | 203.0.113.44 | root | ssh | FAIL | wrong password
2026-03-14T09:02:51Z | 10.0.4.12 | alice | web | OK | GET /dashboard 200

ACTION ∈ {ssh, web, sudo, file} · RESULT ∈ {OK, FAIL, SCAN}. The sample generator and a friendlier best-effort parser handle minor variations too.
